# Late Chunking Baseline Project

Colab-ready scaffold for reproducing the official Late Chunking baseline on a
small BEIR-style retrieval task.

- Paper: <https://arxiv.org/abs/2409.04701>
- Official repository: <https://github.com/jina-ai/late-chunking>
- Primary notebook: `notebooks/01_late_chunking_baseline_colab.ipynb`

## What Late Chunking Is

Traditional chunking splits each document into chunks, then encodes each chunk
independently. Late chunking encodes the full document or long context first,
then mean-pools token representations by chunk span. This scaffold keeps the
official implementation as the baseline source and adds only reproducibility
plumbing around it.

## Open in Colab

After pushing this repository to GitHub, edit the notebook config:

```python
PUBLIC_REPO_URL = "https://github.com/<YOUR_GITHUB_USERNAME>/late-chunking-project.git"
```

Then open:

```text
https://colab.research.google.com/github/<YOUR_GITHUB_USERNAME>/late-chunking-project/blob/main/notebooks/01_late_chunking_baseline_colab.ipynb
```

Use a GPU runtime for `small` or `full` mode.

## Modes

- `smoke`: installs dependencies, clones the official repo, prints environment
  details, prepares logs and a manifest, and avoids forcing a full SciFact run.
- `small`: runs the official `SciFactChunked` baseline and saves logs.
- `full`: intended for multiple tasks. Set `CONFIRM_FULL_RUN = True`; otherwise
  the notebook stops before heavy work.

Default task:

```python
TASKS = ["SciFactChunked"]
```

Optional later task:

```python
TASKS = ["SciFactChunked", "NFCorpusChunked"]
```

## Outputs

Artifacts are saved under `OUTPUT_DIR`, defaulting to
`/content/late_chunking_outputs`:

- `logs/official_<TASK>_stdout.txt`
- `logs/official_<TASK>_stderr.txt`
- `tables/metrics_summary.csv` when metrics can be parsed
- `predictions/` if generated by later work
- `figures/` if generated by later work
- `run_manifest.json`

No training is performed, and no paid API is used.

## Runtime Estimates

- `smoke`: about 5-15 minutes in Colab, dominated by dependency installation.
- `small`: about 20-60 minutes depending on GPU, downloads, and official repo
  behavior.
- `full`: potentially several hours and should be explicitly confirmed.

## Known Risks

- The official repository may change dependencies or output formatting.
- Colab package resolution can vary by runtime image.
- `faiss-cpu` is used by default; GPU FAISS is not required for Phase A.
- Metric parsing is best-effort. Raw logs are the source of truth if parsing
  fails.

## Local Tests

Run CPU-only tests without downloading models or datasets:

```bash
python -m pytest
```

If Colab raises `ModuleNotFoundError: No module named 'latechunk_project'`,
rerun the `Install Project Dependencies` cell. That cell adds `src/` to
`sys.path` before installing the project, so local imports still work if an
editable install is unavailable.

If Colab fails with a `torchcodec` / `libavutil.so` traceback, rerun the latest
notebook from the top. The notebook removes the optional `torchcodec` package
because this text-only retrieval baseline does not need audio/video decoding.
